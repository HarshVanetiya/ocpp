Day 10 — Wallet & Razorpay top-up

Goal: /topup 500 → Razorpay payment link → user pays (UPI/card) → webhook credits the wallet → Telegram confirms.

Flow

flow
/topup 500 ─▶ Payment row (CREATED) ─▶ Razorpay Payment Link ─▶ "💳 Pay ₹500" button
User pays ─▶ Razorpay POST /webhooks/razorpay (payment_link.paid)
           ─▶ verify signature ─▶ Payment PAID + wallet += 500 (one DB transaction) ─▶ Telegram "✅ ₹500 added"

Rules

  • Verify the signature (HMAC-SHA256 of the raw body). Never credit an unsigned request.
  • Idempotent: Razorpay may send the same webhook twice. Only flip CREATED → PAID once.
  • Amounts to Razorpay are in paise (₹500 → 50000).

Tasks

apps/api/src/bot/topup.ts
import Razorpay from "razorpay";
import { InlineKeyboard } from "grammy";
import { prisma } from "@ev/db";
import { bot, getUser } from "./bot";
import { env } from "../env";

const rzp = new Razorpay({ key_id: env.RAZORPAY_KEY_ID!, key_secret: env.RAZORPAY_KEY_SECRET! });

bot.command("topup", async (ctx) => {
  const amount = Number(ctx.match) || 200;
  if (amount < 50 || amount > 10_000) return ctx.reply("Use: /topup 500  (₹50 – ₹10,000)");

  const user = await getUser(ctx);
  const payment = await prisma.payment.create({ data: { userId: user.id, amount } });

  const link = await rzp.paymentLink.create({
    amount: amount * 100,
    currency: "INR",
    description: "EV wallet top-up",
    reference_id: payment.id,
    notes: { paymentId: payment.id },
  });
  await prisma.payment.update({ where: { id: payment.id }, data: { razorpayLinkId: link.id } });

  await ctx.reply(`Top up ₹${amount}:`, { reply_markup: new InlineKeyboard().url(`💳 Pay ₹${amount}`, link.short_url) });
});
apps/api/src/routes/webhooks.ts
import express, { Router } from "express";
import { createHmac, timingSafeEqual } from "node:crypto";
import { prisma } from "@ev/db";
import { bot } from "../bot/bot";
import { env } from "../env";

export const webhooks = Router();

webhooks.post("/razorpay", express.raw({ type: "application/json" }), async (req, res) => {
  const signature = Buffer.from(req.header("x-razorpay-signature") ?? "");
  const expected = Buffer.from(createHmac("sha256", env.RAZORPAY_WEBHOOK_SECRET!).update(req.body).digest("hex"));
  if (signature.length !== expected.length || !timingSafeEqual(signature, expected)) {
    return res.sendStatus(400);
  }

  const event = JSON.parse(req.body.toString());
  if (event.event === "payment_link.paid") {
    const linkId: string = event.payload.payment_link.entity.id;

    const paid = await prisma.$transaction(async (tx) => {
      const flipped = await tx.payment.updateMany({
        where: { razorpayLinkId: linkId, status: "CREATED" },
        data: { status: "PAID", paidAt: new Date() },
      });
      if (flipped.count === 0) return null; // duplicate webhook
      const p = await tx.payment.findUniqueOrThrow({ where: { razorpayLinkId: linkId } });
      return tx.user.update({
        where: { id: p.userId },
        data: { walletBalance: { increment: p.amount } },
      }).then((user) => ({ user, amount: p.amount }));
    });

    if (paid) {
      await bot.api.sendMessage(paid.user.telegramId,
        `✅ ₹${paid.amount} added. Wallet balance: ₹${paid.user.walletBalance}`);
    }
  }
  res.sendStatus(200);
});
Mount webhooks before app.use(express.json()). If JSON parsing runs first, the raw body is gone and every signature check fails.
