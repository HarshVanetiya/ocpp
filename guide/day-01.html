Day 1 — Monorepo setup

Goal: one repo, three packages (apps/api, apps/web, packages/db), Postgres running in Docker.

Tasks

1. Root files

terminal
corepack enable
mkdir -p apps packages
pnpm init
pnpm add -Dw turbo typescript
package.json (root) — replace scripts
{
  "name": "ev-platform",
  "private": true,
  "scripts": {
    "dev": "turbo dev",
    "build": "turbo build",
    "test": "turbo test",
    "db:migrate": "pnpm --filter @ev/db migrate",
    "db:seed": "pnpm --filter @ev/db seed",
    "db:studio": "pnpm --filter @ev/db studio"
  }
}
pnpm-workspace.yaml
packages:
  - "apps/*"
  - "packages/*"

# pnpm 10 blocks install scripts by default. Prisma needs them.
onlyBuiltDependencies:
  - prisma
  - "@prisma/client"
  - "@prisma/engines"
  - esbuild
If pnpm still prints "Ignored build scripts", run pnpm approve-builds and select the Prisma packages.
turbo.json
{
  "$schema": "https://turbo.build/schema.json",
  "tasks": {
    "dev":   { "cache": false, "persistent": true },
    "build": { "dependsOn": ["^build"], "outputs": ["dist/**", ".next/**"] },
    "test":  {}
  }
}
tsconfig.base.json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "resolveJsonModule": true
  }
}

2. Postgres

docker-compose.yml
services:
  db:
    image: postgres:16
    environment:
      POSTGRES_USER: ev
      POSTGRES_PASSWORD: ev
      POSTGRES_DB: ev
    ports: ["5432:5432"]
    volumes: [pgdata:/var/lib/postgresql/data]
volumes:
  pgdata:
terminal
docker compose up -d

3. Packages

terminal
mkdir -p packages/db/src apps/api/src apps/api/scripts
cd packages/db && pnpm init && cd ../..
cd apps/api && pnpm init && cd ../..
pnpm create next-app@latest apps/web --ts --app --tailwind --eslint --src-dir --import-alias "@/*" --use-pnpm

Set the name in each package.json: @ev/db, @ev/api, @ev/web.

terminal — API dependencies
pnpm --filter @ev/api add express ws grammy zod pino cookie-parser jsonwebtoken bcryptjs razorpay
pnpm --filter @ev/api add -D tsx tsup vitest @types/node @types/express @types/ws @types/cookie-parser @types/jsonwebtoken
pnpm --filter @ev/api add @ev/db@workspace:*
apps/api/package.json — scripts
"type": "module",
"scripts": {
  "dev": "tsx watch src/index.ts",
  "build": "tsup src/index.ts --format esm",
  "start": "node dist/index.js",
  "test": "vitest run",
  "sim": "tsx scripts/sim.ts"
}
apps/api/tsconfig.json
{ "extends": "../../tsconfig.base.json", "include": ["src", "scripts"] }
